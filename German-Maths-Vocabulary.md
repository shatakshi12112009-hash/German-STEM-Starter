# ➕ Basic Mathematics

| English | German | Pronunciation | Example |
|----------|---------|---------------|---------|
| Number | Zahl | Tsaal | Die Zahl ist zehn. |
| Addition | Addition | Addi-tsi-on | Die Addition ist einfach. |
| Subtraction | Subtraktion | Sub-trak-tsi-on | Löse die Subtraktion. |
| Multiplication | Multiplikation | Multipli-ka-tsi-on | Die Multiplikation ist leicht. |
| Division | Division | Dee-vee-zee-on | Die Division ist richtig. |
| Fraction | Bruch | Brookh | Ein Bruch hat zwei Zahlen. |
| Decimal | Dezimalzahl | Day-tsi-mal-tsaal | Das ist eine Dezimalzahl. |
| Percentage | Prozentsatz | Pro-tsent-zats | Der Prozentsatz beträgt 50 %. |
